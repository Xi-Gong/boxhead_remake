## 超越原版的功能

### 限时关卡、Boss与本局构筑

单人、本地合作与支持新能力的LAN合作无尽循环，死亡竞赛保持原规则。

v0.3.2 普通关以 **90秒**、Boss关以 **120秒** 为中心，按地图可行走面积和原出生口路程调整：普通关80～105秒，Boss额外30秒。选关界面显示实际时限。暂停、选强化和断线冻结均停表；普通关清空有限目标或存活即可过关，Boss全灭可提前过关。超时不赠送经验或击杀奖励。

僵尸目标量和同时在场上限为v0.3.1的 **40%**；HIGH最多22只，LOW最多16只。只从可达的原出生口进场，不再在玩家附近随机空地刷新。进攻窗口穿插喘息期，远处或隔墙敌人加快接近，接战后恢复各自速度。普通/冲锋者生命×2.5，恶魔/祭司/Boss生命×2；恶魔护甲为生命30%，Boss为40%，护甲消耗后不再生。

新敌人所有可见身体部件采用全新几何建模，仅保留动作骨架和功能锚点。第3关起疾行僵尸侧翼包抄，第6关起臃肿僵尸预警近身重击；第8关起持枪僵尸随机采用四种玩家风格身份与手枪/UZI/霰弹枪，锁定瞄准后发射可躲避的慢弹。屠夫和猎手恶魔从第12/18关加入，第15/20关出现其Boss形态。

波间每人获得进攻、防御、功能各一张强化卡，显示当前→下次效果。**无倒计时、无默认自动选择，必须双方明确确认READY。** 移动/换枪键选择，射击确认；鼠标先选卡，再点READY。P1 **Tab**、P2 **R** 或手柄 **Y** 查询独立属性页，键盘查询键可重绑。进入前按住射击不会误确认，联机属性读取确认态。

| 强化 | 每份效果 |
|---|---|
| 火力 | 武器伤害加成+8% |
| 体魄 | 最大生命加成+10%，存活玩家补新增上限差额 |
| 护盾 | 最大护盾加成+10%，不直接回盾 |
| 弹仓 | 容量训练+8%，收益递减 |
| 快手/步法 | 射速训练+6%/移速训练+4%，收益递减 |
| 穿甲/补给 | 穿甲训练+12%/恢复训练+10%，收益递减 |
| 急救 | 恢复最大生命35% |
| 补弹 | 已拥有武器恢复最大容量35% |

本局加成累计，存档、重试与复生保留，新开局清零。候选排除无收益和已封顶项目。高波次选关分配八类永久属性，并按实际可赚经验推导基础等级，不逐关重放、不预授Boss奖励。现代有限弹仓渐近原容量3倍，只有原生手枪无限弹；各枪设置射速下限。霰弹伤害为原65%并随距离衰减，火箭直接自伤为15%再扣护甲。现代补给恢复上限40%，可由有限补给效率提高；急救/补弹恢复35%并受效率加成。

**裂骨暴君/余烬领主/屠夫/猎手**每5关轮换，普通援军至多1只；关闭恶魔时统一为暴君。Boss技能先锁定预警，攻击后提供恢复窗口，连段逐次重新预警。非致死普通受击不打断Boss技能。击败全部Boss使每人本次所选奖励翻倍，超时存活仍得普通奖励，不增加选择轮次。

第5/10关各1只Boss，第15/20关各2只，第25关起最多3只；击败本关全部Boss立即过关并获得一次翻倍强化，部分击杀后超时仍为普通奖励。每只Boss只有一条简洁的头顶比例血条，不显示数字，统一计入DEVIL。倒计时收进WAVE方框。血条联机读取已确认血量，暂停、离开镜头或击杀后隐藏。

v2可选扩展保存时钟、候选/确认/属性、新敌人身份、当前护甲及待发技能。旧档先按原规则打完当前关，下关迁移且不免费补给、不丢已得进度，过量弹仓按新上限收敛。LAN按依赖协商combat-pve-v2、draft-ready-v1等能力，旧端保留其支持的规则。

五枪模型保留原枪口/握持锚点；普通/附魔子弹、轨迹、火箭及枪口效果区分清楚。变种与Boss的装甲随原身体动画运动；保留经典素材，不为纯美术新增协议字段。

- **存档与重试**：暂停界面 **SAVE & QUIT** 随时存档退出，主菜单 **CONTINUE** 从存档波次续玩；死亡后 **RETRY** 恢复失败波次的开局检查点，没有波次检查点则回到本局起始状态，恢复其中的成长、分数与库存。
- **协作死亡武器箱**：Coop 里玩家死亡时原地掉落红箱，内含其背包全部武器与实际剩余弹药；本人拾取精确还原，队友拾取取两者较优。
- **恶魔补给**：每只基础恶魔等概率掉落一个蓝色护盾、军绿弹药或鲜绿医疗箱，跨波次和存档保留至有效拾取。护盾只补盾，医疗只补血，弹药按当前规则恢复全部已有武器，不解锁新武器。对应状态已满时不消耗箱子，死亡玩家不能领取；同一箱只能领取一次。局域网双方协商新规则后启用，旧端保留原规则。
- **普通红箱**：10%护盾、10%弹药、10%医疗效果，其余70%保留原已有武器候选顺序及权重，移除原回血项。状态已满或奖池为空仍消费，不重抽。固定红箱24秒重生；每20模拟秒在可达空地投放单人1个/合作2个随机红箱，同时最多3/6个，45秒后消失，暂停不计时。
- **起始波次输入（进度解锁）**：`START WAVE` 支持直接输入ASCII十进制数字及左右箭头，范围1至历史最高 `BEST` 波次，现代PvE随历史进度突破100波。允许前导零并规范化；Enter/失焦提交，Esc恢复上次合法值。非法文本弹出游戏内提示并取消开始或切换；每次进入默认第1波，输入不解锁新波次。联机仅房主可编辑，使用房主上限，客机只读同步。
- **统一永久成长**：单人、本地合作和联机共用个人最后一击分数、永久等级及武器强化。普通僵尸2经验、冲锋者4、恶魔10、祭司12、旧Boss50、新Boss70，新普通子种各有奖励，新局1～10级每次升级需2～5经验、11～30级需6～15经验，31级起需20经验且每级再加3；旧局保留保存的曲线。现代PvE等级无上限；击杀分数乘本次升级前个人等级。单人一个面板、合作两个，中间WAVE内显示波次和时钟；普通关人数包含尚未刷出的清关目标，Boss计在DEVIL下。暂停可分别查看强化。重试恢复本关检查点成长与库存；选关按限时参考经验给基础等级，保留难度下限。本地合作保留共享镜头和操作，死亡竞赛保持原规则。旧v2本地存档一次性转换，保留总分、当前血盾、武器与弹药；双人旧分平分，奇数余量归P1。
- **成长生存能力**：新局生命和护盾上限从200开始，升至2～10级每级增加4、11～30级每级增加6、31级起每级增加10，再计本局强化。旧成长档保留 `200＋4×(等级−1)`。活着升级增加生命上限差额，不补护盾。僵尸、恶魔近战及火球命中前有盾时，该击（含破盾）不打断、不僵直、不击退；伤害照常扣盾、溢出扣血，致死仍死亡。合作重生保留等级、恢复满生命、护盾清零；原自然回血公式不变。
- **四档生存难度曲线**：单人及合作分别调整Beginner、Intermediate、Expert、Nightmare的刷怪节奏、同时在场上限和速度上限。现代限时关在有限且大幅减少的目标量内补怪，旧规则每波预算仍至多200只僵尸、10只恶魔（含子种）；敌人血量和伤害随参考成长等级持续增强，联机双方协商支持后才启用。参见[平衡审计与爆炸性能实测](verification/v0.2.8/README.md)。
- **无限武器成长**：新局11～30级每级增加1%伤害、0.5%有限弹仓，31级起每级增加2%伤害、1%有限弹仓；旧成长档保留125级后每级增加125级伤害的1%、有限容量增加max(1,ceil(125级容量×0.005))。仅补新增容量差额，现代容量受上限约束，旧过量在迁移时收敛；存档恢复当前血盾弹量，不额外发奖。
- **裂骨冲锋者与余烬祭司**：第8/20波开始替换原名额，同时至多四只冲锋者、一只祭司。冲锋者蓄力0.6秒后沿锁定方向冲锋至多四格，受击打断；祭司以0.9秒预警火印替代对人火球，燃烧1.6秒、最多四次伤害。火区有墙体与重叠伤害保护，死亡取消未点燃火印，换波清理。
- **紫色附魔武器**：冲锋者独立50%普通红箱与原连杀保底合并，同次最多一箱。祭司必掉一个箱，30%紫色附魔，余下70%护盾/弹药/医疗等概率。紫箱附魔当前手持武器，本身不补弹，伤害+35%、普通子弹额外穿透两个敌人；轨道枪保留原无限敌人贯穿，爆炸边缘至少保留75%强化伤害且实体墙阻挡。武器弹药耗尽前，红箱与Devil弹药箱补给、升级和切枪均保留附魔，新弹药同样强化；最后一发仍附魔，耗尽后再补弹或重新获得同类武器不恢复。死亡武器箱、存档和回滚保留附魔标记，旧档仍有附魔余量的武器转换为持续附魔且不赠送弹药。原生无限弹药持续附魔；弹药文字、曳光和爆炸呈紫色，手持假墙时保留箱子。LAN双方须支持persistent-enchantment-v1，旧能力保留旧规则。
- **稳定拾取与界面间距**：发奖先同步个人上限，容量受现代上限约束；单武器红箱只恢复抽中的武器。P1/P2白字由确认态HUD队列显示，最多三行、22px行距、平滑让位、三秒寿命及末半秒淡出，暂停冻结。菜单保留原美术，大厅恢复/重试与设置并排，主操作和返回分行。
- **局域网联机**（仅便携版）：建房、自动发现或输 IP 加入合作与对战。本机输入在下一模拟 tick 执行，不再等待对端；回滚纠正迟到输入，本机枪声即时反馈，画面按显示器刷新率插值。UDP 冗余输入配合 TCP 可靠回退；短时断线从输入历史恢复，对端重启则在 30 秒重连窗口内从检查点续局。任一玩家可在结算界 Retry。确认后的玩法保持一致，较差链路下预测画面可能回正；[实测收益与成本](verification/v0.2.7/README.md)有完整记录。
- **用户数据统一存放**：所有版本（含便携版）的存档与设置都保存在 `%USERPROFILE%\.boxhead` 一个文件夹里，首次运行自动迁移旧数据，便于管理与备份。
- **房间设置**：等待房间和开局设置页共用面板，房主调整难度、速度、恶魔、角色碰撞、友伤及适用胜利条件，客机实时只读查看。开局后固定，续局沿用原设置；合作关闭友伤后子弹穿过队友继续命中后方敌人，移动碰撞独立控制。
- **显示与声音**：确认击杀的飘分只播放一次，平滑飞向对应玩家实际分数区域，适配缩放和暂停。爆炸整屏闪光减弱，保留爆炸动画与玩法。音频启动失败或播放异常可自动恢复，保留静音选择。
