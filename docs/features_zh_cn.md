## 超越原版的功能

### 限时关卡、Boss与本局构筑

单人、本地合作与支持新能力的LAN合作无尽循环，死亡竞赛保持原规则。

v0.3.4 普通关以 **90秒**、Boss关以 **120秒** 为中心，按地图可行走面积和原出生口路程调整：普通关80～105秒，Boss额外30秒。选关界面显示实际时限。暂停、选强化和断线冻结均停表；普通关清空有限目标或存活即可过关，Boss全灭可提前过关。超时不赠送经验或击杀奖励。

普通关按实际时限计算有限目标，沿用40%预算系数；HIGH并发最多22只，LOW最多16只。只从可达的原出生口进场，不在玩家附近随机空地刷新。进攻窗口穿插喘息期，远处或隔墙敌人加快接近，接战后恢复各自速度。普通僵尸生命保留×2.5，小红/Boss保留×2；所有敌人均无护甲。

普通敌群仅原版僵尸与原版火球小红。新版取消全部冲锋僵尸、技能、预警和额外50%红箱随机调用；旧能力对局与历史夹具隔离保留原规则。

波间每人从进攻、防御、功能各一张卡中选择，显示精确当前→升级值。**无倒计时、无自动选择，双方确认READY后继续。** 移动/换枪键选择，A或射击确认；鼠标先选卡再点READY。**X**、P1 **Tab**、P2 **R**仅在结算时查看属性，提示跟随实际改键。单人显示本人，本地双人共同开关P1/P2，联机各自只显示本人、独立开关；队友选择与准备不受影响。查看屏蔽对应选择输入，关闭等待持键释放。联机读取确认态。整个窗口采用原版头像、暖纸面、粗描边、大图标和明确收益层级。

| 火力 | 武器伤害加成+8% |
| 体魄 | 最大生命加成+8%，存活玩家补新增上限差额 |

| 弹仓 | 容量训练+8%，收益递减 |
| 快手/步法 | 射速训练+6%/移速训练+4%，收益递减 |
| 补给 | 回血/弹药恢复训练+10%，收益递减 |
| 附魔续航 | 耐久训练+10%，收益递减 |
| 急救 | 恢复最大生命35% |
| 补弹 | 已拥有武器恢复最大容量35% |

本局加成累计，存档、重试与复生保留，新开局清零。候选排除无收益和已封顶项目。高波次选关分配八类永久属性，并按实际可赚经验推导基础等级，不逐关重放、不预授Boss奖励。现代有限弹仓渐近原容量3倍，只有原生手枪无限弹；各枪设置射速下限。霰弹伤害为原65%并随距离衰减，火箭直接自伤为15%再扣护甲。医疗/弹药补给恢复上限40%，可由有限补给效率提高；护甲箱直接补满；急救/补弹恢复35%并受效率加成。

**原生小红Boss**每5关出现，关闭恶魔时改为无冲锋技能的原生僵尸Boss。保留1～3成员及两个普通增援名额。小红Boss相对旧版同波原生值增加15%移速、15%攻击动画推进、10%伤害，弹速/射程不变，首次攻击按成员序号错开0.25秒。击败全部Boss使各自奖励翻倍，超时存活仍得普通奖励。

第5/10关各1只Boss，第15/20关各2只，第25关起最多3只；击败本关全部Boss立即过关并获得一次翻倍强化，部分击杀后超时仍为普通奖励。每只Boss只有一条简洁的头顶比例血条，不显示数字，统一计入DEVIL。倒计时收进WAVE方框。血条联机读取已确认血量，暂停、离开镜头或击杀后隐藏。

仍使用v2存档容器及可选规则字段。旧档在支持v3时读入即转换：保留成长和库存，生命/护甲按剩余比例结算，退出兵种按家族转换，旧穿甲点数和卡片转火力；保留既有时钟及完成比例，新档重复读取不再折算。LAN按依赖协商combat-pve-v3等能力，旧端保留其支持的规则，并在修改前拒绝v3存档。

五枪模型保留原枪口/握持锚点；普通/附魔子弹、轨迹、火箭及枪口效果区分清楚。僵尸/小红Boss分别使用44×5/40×5逻辑像素生命条，不显示护甲条，玩家血条保持原设计。

- **存档与重试**：暂停界面 **SAVE & QUIT** 随时存档退出，主菜单 **CONTINUE** 从存档波次续玩；死亡后 **RETRY** 恢复失败波次的开局检查点，没有波次检查点则回到本局起始状态，恢复其中的成长、分数与库存。
- **协作死亡武器箱**：Coop 里玩家死亡时原地掉落红箱，内含其背包全部武器与实际剩余弹药；本人拾取精确还原，队友拾取取两者较优。
- **恶魔补给**：击杀小红及其Boss一次随机掉落医疗/护甲/附魔/弹药箱，各25%，跨波次和存档保留至有效拾取。医疗只补血、护甲只补盾、弹药补已有武器、附魔作用于手持武器。对应状态已满时不消耗箱子，死亡玩家不能领取；同一箱只能领取一次。旧端保留原规则。
- **普通红箱**：仅保留原已有武器候选顺序和权重，补给抽中的武器，不再提供医疗、护甲或全背包补弹。奖池为空或武器已满仍消费，不重抽。固定红箱24秒重生；每20模拟秒在可达空地投放单人1个/合作2个随机红箱，同时最多3/6个，45秒后消失，暂停不计时。
- **起始波次输入（进度解锁）**：`START WAVE` 支持直接输入ASCII十进制数字及左右箭头，范围1至历史最高 `BEST` 波次，现代PvE随历史进度突破100波。允许前导零并规范化；Enter/失焦提交，Esc恢复上次合法值。非法文本弹出游戏内提示并取消开始或切换；每次进入默认第1波，输入不解锁新波次。联机仅房主可编辑，使用房主上限，客机只读同步。
- **统一永久成长**：单人、本地合作和联机共用个人最后一击分数、永久等级及武器强化。普通僵尸2经验、小红10、Boss50，新局1～10级每次升级需2～5经验、11～30级需6～15经验，31级起需20经验且每级再加3；旧局保留保存的曲线。现代PvE等级无上限；击杀分数乘本次升级前个人等级。单人一个面板、合作两个，中间WAVE内显示波次和时钟；普通关人数包含尚未刷出的清关目标，Boss计在DEVIL下。暂停可分别查看强化。重试恢复本关检查点成长与库存；选关按限时参考经验给基础等级，保留难度下限。本地合作保留共享镜头和操作，死亡竞赛保持原规则。旧v2本地存档一次性转换，保留总分、血盾剩余比例、武器与弹药；双人旧分平分，奇数余量归P1。
- **成长生存能力**：初始160血、40甲容量且空甲。等级基础血量2～10级每级+2，11～30级+3，31级起+4。护甲上限为 `min(floor(基础血量×25%×(1+6%×护甲点数)), floor(实际血量×40%))`，使用独立青色细条。等级/护甲卡不补甲，每个有效护甲箱直接补满且不受效率影响；满甲/死亡玩家不消耗且不阻挡有效队友。护甲1:1吸收，溢出扣血，致死正常；保留有甲受击抗打断、自然回血与升级生命差额。
- **四档生存难度曲线**：单人及合作分别调整Beginner、Intermediate、Expert、Nightmare的刷怪节奏、同时在场上限和速度上限。现代限时关在有限且大幅减少的目标量内补怪，旧规则每波预算仍至多200只僵尸、10只恶魔（含子种）；敌人血量和伤害随参考成长等级持续增强，联机双方协商支持后才启用。参见[平衡审计与爆炸性能实测](verification/v0.2.8/README.md)。
- **无限武器成长**：新局11～30级每级增加1%伤害、0.5%有限弹仓，31级起每级增加2%伤害、1%有限弹仓；旧成长档保留125级后每级增加125级伤害的1%、有限容量增加max(1,ceil(125级容量×0.005))。仅补新增容量差额，现代容量受上限约束，旧局已得过量弹药仍可有限消耗；存档恢复当前血盾弹量，不额外发奖。
- **紫色附魔武器**：紫箱补满手持武器独立耐久，不增加弹药。成功发射/放置一次扣一点，霰弹齐射算一次，派生/穿透/连锁不重复扣，放置失败不扣。空弹仍保留耐久且可吃紫箱，普通补弹/重建不恢复耐久；最后一次攻击及其派生保留15%增伤与原附魔效果，耗尽恢复普通。紫色细条与属性页显示剩余/上限。死亡箱耐久取较大值不相加，空弹附魔不生成弹药。旧持续标记一次转换满预算，旧有限库存按剩余量转换。假墙不附魔，旧联机能力继续保持原语义。
- **A/Y快捷武器**：已解锁武器零弹也可选。战斗中短按A/Y切换，长按0.8秒绑定当前武器、替换或再次长按解绑；同枪只占一个键，显示字母及进度条。绑定按玩家独立、本局保留，死亡、换波、重试、存档、断线恢复均保留，新局清空。B/LT/RT开火，菜单/结算A确认；暂停、失焦、断开、换枪及进入结算取消长按。
- **稳定拾取与界面间距**：发奖先同步个人上限，容量受现代上限约束；单武器红箱只恢复抽中的武器。P1/P2白字由确认态HUD队列显示，最多三行、22px行距、平滑让位、三秒寿命及末半秒淡出，暂停冻结。菜单保留原美术，大厅恢复/重试与设置并排，主操作和返回分行。
- **局域网联机**（仅便携版）：建房、自动发现或输 IP 加入合作与对战。本机输入在下一模拟 tick 执行，不再等待对端；回滚纠正迟到输入，本机枪声即时反馈，画面按显示器刷新率插值。UDP 冗余输入配合 TCP 可靠回退；短时断线从输入历史恢复，对端重启则在 30 秒重连窗口内从检查点续局。任一玩家可在结算界 Retry。确认后的玩法保持一致，较差链路下预测画面可能回正；[实测收益与成本](verification/v0.2.7/README.md)有完整记录。
- **用户数据统一存放**：所有版本（含便携版）的存档与设置都保存在 `%USERPROFILE%\.boxhead` 一个文件夹里，首次运行自动迁移旧数据，便于管理与备份。
- **房间设置**：等待房间和开局设置页共用面板，房主调整难度、速度、恶魔、角色碰撞、友伤及适用胜利条件，客机实时只读查看。开局后固定，续局沿用原设置；合作关闭友伤后子弹穿过队友继续命中后方敌人，移动碰撞独立控制。
- **显示与声音**：确认击杀的飘分只播放一次，平滑飞向对应玩家实际分数区域，适配缩放和暂停。爆炸整屏闪光减弱，保留爆炸动画与玩法。音频启动失败或播放异常可自动恢复，保留静音选择。

全部偏差登记在 [`src/game/deviations.ts`](../src/game/deviations.ts) 并收录于 [`PARITY.md`](../PARITY.md)：
赞助商内容（CMG Logo、在线排行榜、外链）改为本地高分；任意刷新率下保持原版 50fps 逻辑。

### 附魔耐久与续航

基础耐久：手枪60、UZI120、霰弹/轨道30、火箭/手雷24、油桶/地雷/遥控炸药12。
令 `x=0.01×(等级−1)+0.10×续航点数`，上限为 `floor(基础值×(1+2x/(2+x)))`，渐近三倍。Boss奖励计两点；成长只给未耗尽附魔补新增上限差额，不重新激活已耗尽附魔。旧构筑不重分配。

v2存档新增可选能力、绑定和耐久字段。旧护甲按剩余比例迁移一次；旧冲锋Boss转为原生家庭，保留血量比例、成员位置和计时。旧端在修改世界前拒绝不支持的新存档。
