# 🎯 v0.3.2 — Room to Maneuver

Fewer, tougher enemies, distinct new silhouettes and more deliberate co-op builds.

## ✨ Highlights

- Zombie objectives and active limits are reduced by 60%. Enemies enter through reachable original entrances, with approach pacing and recovery gaps. Ordinary rounds run 80–105 seconds around a 90-second target; Boss rounds add 30 seconds.
- Existing enemies have substantially more health. Devils and Bosses gain consumable armor. New runners, heavy brutes, butchers and hunters have entirely new visible models; butcher/hunter Boss forms add warned cleaves and dodgeable projectile fans. Player-inspired gunner zombies carry pistols, UZIs or shotguns.
- Upgrade drafts have no countdown or automatic default. Both players explicitly confirm before advancing. Refined cards preview benefits, and independent attribute sheets open with P1 Tab, P2 R or gamepad Y, with configurable keyboard bindings.
- Broader offense, defense and utility choices use diminishing movement, cadence, capacity, penetration and recovery gains. Finite ammunition and per-weapon cadence limits curb runaway builds; shotgun damage/range scaling and rocket self-damage are rebalanced.

## 🛠️ Fixes and compatibility

- Fixed P2 draft navigation, consecutive short taps and hidden gamepad cursor releases accidentally confirming choices.
- Fixed empty Boss rounds on maps whose dedicated Devil entrances are blocked; Devils use reachable original zombie entrances in that case.
- Clarified partial-supply recovery messages. Saves, checkpoints, depleted armor, pending skills and rewards retain their state. Older saves finish the current wave before migrating; LAN extensions require mutual support.
